# 🇵🇰 Pakistan General Knowledge Quiz

A simple and interactive General Knowledge Quiz application developed using **Python and Streamlit**. It allows users to test their knowledge about Pakistan through five questions and displays their final score.

## ✨ Features

- Displays five general knowledge questions about Pakistan.
- Allows users to enter their answers through a web interface.
- Automatically checks answers.
- Awards 10 points for each correct answer.
- Calculates the total score out of 50.
- Displays correct and incorrect answer feedback.
- Shows a pass message if the score is 30 or above.
- Accepts answers regardless of uppercase or lowercase letters.

## 🛠️ Technologies Used

- Python
- Streamlit

## 📋 Questions Included

1. What is the national animal of Pakistan?
2. Who was the first Prime Minister of Pakistan?
3. Who was the founder of Pakistan?
4. Who was the national poet of Pakistan?
5. What is the national language of Pakistan?

## 🏆 Scoring System

- Each correct answer earns 10 points.
- Maximum score: 50 points.
- Passing score: 30 points.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone YOUR_REPOSITORY_URL
```

**2. Install Streamlit**

```bash
pip install streamlit
```

**3. Run the application**

```bash
streamlit run app.py
```
